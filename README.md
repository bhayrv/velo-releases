# Velo for Android

Official APK downloads and release notes for Velo.

## Download

Get the latest signed APK from [Releases](https://github.com/bhayrv/velo-releases/releases/latest).

Open the APK on your Android phone to install it. When updating an existing production installation, install over it to preserve your data.

Velo 2.0.1 and later check this repository for updates when the app launches. Android asks for your approval before installing an update.

This repository contains download information and release assets.
